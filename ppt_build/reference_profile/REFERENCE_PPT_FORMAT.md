## 总体规格

- 页面尺寸：13.333 x 7.5 英寸，16:9 宽屏。
- 页数结构：封面 1 页，内容 7 页，结束页 1 页。
- 主字体：Microsoft YaHei，全文统一。
- 背景：浅青绿色 `#EFF9F6`。
- 主色：深青绿 `#0E7C86`。
- 标题深色：墨绿 `#123B42`。
- 正文色：偏灰的深绿 `#3F5E63`。
- 辅助色：浅青绿面板 `#E3F5F1`、白卡片 `#FFFFFF`。
- 点缀色：橙 `#E96F4A`、浅橙 `#FDE8DF`、深橙棕 `#B47A1E`。
- 图片素材极少，正文图标为程序占位图，不作为必要模板元素。

## 版面规律

- 内容页页首统一为：左上角深青绿圆角编号块，内部白色两位章节号，字号 15pt；右侧同行为章节标题，字号 25-27pt，深色加粗。
- 页首下方通常放一条浅青绿色横幅，用于一句导入说明，字号约 14.5pt。
- 主体以白底圆角卡片为主，卡片带浅绿色柔和阴影。
- 卡片内部常见“小圆角图标位 + 标题 + 说明文字”的组合。
- 标题字号：卡片标题 12.5-15pt；正文 11-13pt；页脚 8.5-9pt。
- 页脚固定为：左侧“姓名 ｜ 项目名 · 场景”，右侧“当前页 / 总页数”。
- 结束页居中，主标题“谢谢聆听”约 76pt，副标题约 18pt。

## 页面组织

- 封面：极简，浅色背景，居中大标题“开 题 报 告”，下方项目名称、姓名、学号、班级、指导教师。
- 内容页：每页一个主题，通常两栏或三栏，信息块数量控制在 3-6 个。
- 结束页：居中感谢语。

## 生成规则

1. 保持 16:9 尺寸，全部使用 Microsoft YaHei。
2. 延续浅青绿背景与白卡片结构，不做深色主题。
3. 内容页统一使用左上编号块 + 章节标题 + 浅色导入横幅 + 圆角卡片。
4. 每页控制在 3-6 个信息块，文字直接表述，不写长句堆砌。
5. 页脚固定保留，并更新为当前用户姓名、项目名和页码。
6. 重要对比或流程可用浅色面板区分，但保持整体简洁。
7. 生成后需要检查文字是否溢出、卡片是否对齐、颜色是否偏离色板。
